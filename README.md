# 制作物ポートフォリオ

AI活用・業務自動化・Web制作の相談につなげる、根津仁志のポートフォリオ。
全38件（制作済み33件・制作／検証中3件・構想中2件）を収録。制作済みのうち公開・稼働中は16件です。件数は `PROJECTS` 配列から自動集計します。

🔗 **公開サイト**: https://sasukewebjob-ai.github.io/portfolio/

## ページの流れ

1. 何を相談できるか・自動化の具体例
2. 代表例3件（予約・受付の実店舗への応用／LINEタスク管理／AIカンパニー）
3. 制作者プロフィールと指導・登壇実績
4. 制作物一覧と検索
5. LINEでの相談

分野：業務自動化・AI活用／業務効率化ツール／Web制作・集客／現場オペレーション支援／ゲーム・エンタメ。

ブラウザで `index.html` を開くだけで表示できます。生成り・墨・朱を基調とし、PC・タブレット・スマートフォン向けのレイアウトを用意しています。

## 閲覧・更新方法

- 各分野の先頭3件を表示。「ほかの○件を見る」でその分野をすべて表示します。
- キーワード・分野・業種・制作状況を組み合わせて検索できます。絞り込み中は該当する全件を表示します。
- キーワードは空白区切りのAND検索。全角英数字にも対応します。
- 詳細には課題・成果・使用技術・3つの活用例を掲載。制作・検証中は「実装・検証状況」、構想中は「現在の検討状況」を表示します。これらは「制作済み」の件数に含めません。
- `/` で検索欄へ移動。詳細は `Esc` で閉じ、元のボタンにフォーカスを戻します。
- 新しい制作物は `index.html` の `PROJECTS` 配列に追加します。カテゴリ・件数・検索対象は自動更新されます。
- 代表実績は `data-project` に記載したタイトルと `PROJECTS` のタイトルで詳細を連携します。タイトル変更時は両方を更新してください。

業種の活用例は応用アイデアであり、その業種での導入実績を示すものではありません。追加9件とAIカンパニーは、2026-09-10のローカルフォルダ調査で確認した説明・実装・開発記録を基に掲載しています。元の28件とプロフィールは従来の掲載情報を維持しています。各制作物そのものの動作を今回再検証したわけではありません。
